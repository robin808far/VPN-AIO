# Project documentation

The repository root keeps the main README, its translations, and the local
`HANDOFF.md`. Other Markdown documentation is grouped here by purpose.

- [Guides](guides/) — user-facing feature and upgrade guides.
- [Reference](reference/) — API and supported-distribution reference material.
- [Architecture](architecture/) — architecture notes and diagrams.
- [Plans](plans/) — research, implementation plans, and work-in-progress notes.
- [Releases](releases/) — release notes and version-specific validation records.
- [History](history/) — repository history and migration records.

Feature guide: [Happ subscription management](guides/HAPP.md).

Release notes are in `releases/`; their corresponding validation and provenance
records are in `releases/validation/`.
